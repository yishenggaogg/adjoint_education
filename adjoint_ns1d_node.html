一维层流 Navier–Stokes 方程的离散伴随：格点格式

Discrete adjoints for one-dimensional laminar Navier–Stokes: node-centred

从 Euler 的守恒通量继续，加入分子黏性、黏性功和热传导。我们在等截面的光滑可压缩流中逐步构造残差、matrix-free tangent 与 adjoint，再求温度和热流目标对热源及物性参数的导数。默认参数下入口 M≈0.30、Re=ρuL/μref\mu_{\mathrm{ref}}≈2.3、Pe=Re·Pr≈1.7，黏性和导热在整个区间都起作用。面向学过微积分、线性代数和数值方法的本科生；交互图和播放器来自本页的实时计算，图 1、图 2 是示意图，第 14、15 节的表是离线数据。

Continue from Euler fluxes by adding molecular viscosity, viscous work and heat conduction. For smooth compressible flow of constant area, build residuals, matrix-free tangents and adjoints, then differentiate temperature and heat-flux objectives with respect to heating and transport. With the default parameters the inlet has M≈0.30, Re=ρuL/μref\mu_{\mathrm{ref}}≈2.3 and Pe=Re·Pr≈1.7, so viscosity and conduction act over the whole interval. Calculus, linear algebra and numerical methods are the prerequisites. 第 1 节Section 1

网格：算例、未知量与数组编号

Mesh: the model, its unknowns and array indexing

先明确这个算例求什么

What this model actually solves

本页求解等截面、平面一维、可压缩层流的稳态问题。未知量只随轴向位置变化，横向速度为零；黏性来自分子应力，传热来自 Fourier 热传导。它不解析管壁边界层，不含湍流模型，也不是变截面喷管的黏性修正。教学重点是：同一段残差程序如何产生原始解、精确 tangent 乘积和精确转置乘积。

This page solves steady, compressible, plane one-dimensional laminar flow at constant area. Unknowns vary only axially and transverse velocity is zero. Molecular stress and Fourier conduction supply viscous transport. It resolves neither duct-wall boundary layers nor turbulence and is not a viscous correction to a variable-area nozzle. The teaching focus is how one residual program supplies the primal solution, exact tangent products and exact transpose products.

物理模型与离散运算的分界

Separate the physical model from discrete operations

物理通量包含对流部分与黏性部分。下面先给出状态函数；它们接收一个三分量状态，而不是整个网格。采用无量纲气体常数 1，γ=1.4\gamma=1.4、cv=2.5c_v=2.5、cp=3.5c_p=3.5。连续本构关系中的速度和温度空间导数，在程序里必须由明确的差分模板替代；从本节起，黏性面梯度统一记作 Gfu,GfTG_f^u,G_f^T。

The physical flux contains convective and viscous parts. The state functions below accept one three-component state, not the whole mesh. The nondimensional gas constant is one, with γ=1.4\gamma=1.4, cv=2.5c_v=2.5, cp=3.5c_p=3.5. Spatial derivatives in the continuous constitutive law must be replaced by specified difference stencils in the program. Discrete viscous face gradients are denoted Gfu,GfTG_f^u,G_f^T throughout the main text.

The factor 4/34/3 follows from three-dimensional Newtonian stress under Stokes' hypothesis restricted to plane motion. There is no molecular mass diffusion. The viscous energy flux contains both viscous work and conduction; omitting either changes the primal problem and its derivative. Net flux is convection minus viscosity: the viscous energy flux is uτ−qu\tau-q, so subtracting it puts +qf+q_f into the net flux, and since qf=−κfGfTq_f=-\kappa_fG_f^T itself carries a minus sign, the conduction term in the net flux is −κfGfT-\kappa_fG_f^T.

In the Sutherland law, 1.4=1+S1.4=1+S with the nondimensional Sutherland constant S=0.4S=0.4, so that μ(1)=μref\mu(1)=\mu_{\rm ref}; it is not the ratio of specific heats γ\gamma. The input μref\mu_{\rm ref} is already scaled by reference density, length and velocity; no additional 1/Re1/Re is applied. The order switch changes reconstruction for convection and objective quadrature states. Both modes retain centred viscous differences, the same boundary closures and the same transport law. Three-point node endpoint gradients are second order for smooth point values; this does not establish second-order cell boundary gradients for cell averages, as explained in Section 3. Rusanov-form numerical dissipation is not molecular viscosity.

第 3 节Section 3

Boundary conditions: what is prescribed and how it enters the fluxes

先列出物理约束，再写成实际边界映射

From physical constraints to implemented boundary maps

加热问题入口规定 ρb=1,ub=0.35,Tb=a4\rho_b=1,u_b=0.35,T_b=a_4，出口规定法向总应力 pf−τf=a5p_f-\tau_f=a_5 与 qf=0q_f=0。它没有同时指定出口压力和零应力。制造解问题仍使用同一入口，出口改为规定 ub=0.35,Tb=a5u_b=0.35,T_b=a_5。两种闭合是不同的边值问题，不能把它们的伴随边界项混用。

These are different boundary-value problems and their adjoint boundary contributions cannot be interchanged.

For nodes, summing final constraint rows is not a conservation budget. Counting conditions alone proves neither continuous well-posedness nor discrete nonsingularity; these are separate questions about the current branch and its verification.

Each JVP with a unit state seed v=ejv=e_j and the parameter seed a˙=0\dot a=0 gives R˙h=Ahej\dot R_h=A_he_j, one column. Transpose the complete exact matrix, then factor it by partial-pivot LU. This stores a dense matrix and is explicitly not a matrix-free solve. Both spatial orders use their actual residual's exact matrix, not the preconditioning matrix.

PpivAhT=LLUULU,LLUy=Ppiv(−jU),ULUψh=y.\mathsf P_{\rm piv}A_h^T=L_{\rm LU}U_{\rm LU},\qquad L_{\rm LU}y=\mathsf P_{\rm piv}(-j_U),\qquad U_{\rm LU}\psi_h=y.

Ppiv\mathsf P_{\rm piv} 是行置换矩阵，与 GS 的 PhP_h 无关；ULUU_{\rm LU} 是上三角因子，与流场状态 UiU_i 无关。每步选当前列绝对值最大的主元并交换整行，包括之前保存的下三角乘数。随后前代、回代，最后用原始精确转置接口检查真残差。

The row permutation Ppiv\mathsf P_{\rm piv} is unrelated to the GS matrix PhP_h, and upper factor ULUU_{\rm LU} is unrelated to flow state UiU_i. Each stage selects the largest-magnitude pivot in the current column and swaps complete rows, including previously stored lower multipliers. Forward and backward substitution follow, then the original exact transpose interface checks the true residual.

AhTA_h^T consists of 3×33\times3 blocks (dimension 39 here for N = 12). The face stencils of Appendix B give the bandwidths: 5 below and 8 above at first order (the upper bandwidth 8 comes from the three-point one-sided differences of the outlet constraint rows), and 8 on both sides at second order. The first first-order swap happens at k=8k=8: the current diagonal entry has magnitude 6.65 and row 10 has 8.15 in the same column, so the two rows are exchanged.
