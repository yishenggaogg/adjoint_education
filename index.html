离散伴随教学页

Discrete adjoint, taught page by page · 中文 / English

两个单文件、可交互的网页，把非结构网格有限体积法的全离散伴随从头到尾讲一遍： 从一个面上的一维通量开始，把同一个循环依次改写成 primal、matrix-free 前向与 matrix-free 伴随， 再做伴随求解、几何导数，最后用有限差分逐项校验。两页结构完全平行，可以并排对照阅读。

格心格式

Cell-centred finite volume

未知量是单元平均值。物面无滑移只能弱加——通量里取常数右状态，和入流面结构相同。

24 个单元 · 48 个面 · nnz(A) = 88
adjoint_cell.html

格点格式

Node-centred, median-dual

未知量在节点上。壁面节点本身就是未知量，所以无滑移是强加——整行替换。

24 个节点 · 80 个面 · nnz(A) = 120
adjoint_node.html

两页都是自包含的单个 HTML 文件：不联网、不需要构建、不需要服务器，直接打开即可。 页面右上角可切换中文 / English。
Both pages are self-contained single HTML files — no network, no build step, no server. A 中文 / English toggle sits in the top-right corner of each page.

每页讲什么 / What each page covers

  • 网格、一维通量与边界条件 — mesh, the one-dimensional flux, boundary conditions
  • 残差 = 一个循环：收集、计算、分发 — the residual as one gather–compute–scatter loop
  • 同一个循环改写成 matrix-free 前向 Av 与伴随 A⁠Tw，每一行都能逐句播放
  • 伴随求解、几何导数 dR/dX 与 dL/dX — the adjoint solve and the geometric derivatives
  • 点积测试与有限差分校验，以及差分校验本身的陷阱 — the dot-product test, and where finite differences mislead

页面上的数字都是实测的 / Every number is measured

页面引用的每一个数值都在浏览器里现场算出，而不是写死的文字：点积测试 8.9e−16（格心）／ 6.7e−16（格点），梯度对全链路中心差分 5.4e−11／5.1e−11。
