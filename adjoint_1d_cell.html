一维 Burgers 方程的离散伴随：格心格式

Discrete adjoints for one-dimensional Burgers: cell-centred scheme

算例是区间 [0,1][0,1] 上带源项的一维 Burgers 方程：左端给定入口值，右端流出，未知量放在单元中心。本页从一个面上的通量出发，依次写出残差、前向（tangent）与伴随（adjoint），再用它们计算源项和入口值的灵敏度。每个面循环都可以逐步播放；切换一阶与二阶，可以看到重构怎样改变计算模板和收敛精度。The test case is the one-dimensional Burgers equation with a source on [0,1][0,1]: a prescribed inlet value on the left, outflow on the right, and unknowns at cell centres. Starting with the flux on one face, this page builds the residual, the forward (tangent) and the adjoint, then uses them to compute sensitivities to the source and inlet value. Each face loop can be played step by step. Switching between first and second order shows how reconstruction changes the stencil and accuracy.

第 1 节Section 1

网格：未知量放在哪里

Mesh: where the unknowns live

先把物理问题、网格和数组分开

Separate the physical problem, mesh and arrays

假设你已经学过微积分、矩阵乘法、Newton 法和线性方程的迭代求解。本页要连接这些知识：先把一个微分方程写成有限个非线性代数方程，再求“输入改变一点，解和目标函数会改变多少”。你不需要先学自动微分或最优化；前向与伴随都从链式法则和矩阵转置开始。

This page assumes calculus, matrix multiplication, Newton’s method and iterative linear solvers. We connect them by turning a differential equation into finitely many nonlinear equations, then asking how a small input change affects the solution and an objective. Automatic differentiation and optimisation are not prerequisites: forward and adjoint calculations start with the chain rule and matrix transposition.

用 NN 表示原始区间数，h=1/Nh=1/N 表示网格宽度，MM 表示未知量个数。数组从 0 开始编号。格心格式有 M=NM=N；格点格式有 M=N+1M=N+1。网格位置 xix_i 是已知几何数据，未知量 uiu_i 是要解出的数值，二者不能混淆。

Let NN be the number of primal intervals, h=1/Nh=1/N the spacing and MM the number of unknowns. Arrays use zero-based indices. Cells have M=NM=N unknowns; nodes have M=N+1M=N+1. Coordinates xix_i are known geometric data; values uiu_i are numbers to solve for.

格心格式把每个区间本身作为控制体，未知量是区间平均值，画在中心只是表示它的存储位置。一个单元有左、右两个边界面；在一维，“面”是一个点。积分方程仍需要该点的通量，不能因为面没有长度就把它省去。

For a cell scheme, each interval is a control volume. Its unknown is an interval average; the centre marks where it is stored. Each cell has a left and a right face. In one dimension a face is a point, but the integrated equation still needs the flux at that point.

要离散的方程与面上的通量

The equation to discretise and the flux on a face

要离散的方程

The equation to discretise

研究光滑正解分支 u>0u>0 上带源项的定常 Burgers 方程。当前源项为 s=0.5s=0.5，入口为 uin=1u_{in}=1；精确解为 u=1+xu=\sqrt{1+x}。目标源项是 sin⁡(πx)\sin(\pi x)。本例不含激波，二阶格式使用无斜率限制器的线性重构。

We study steady Burgers with a source on the smooth positive branch u>0u>0. The current source is s=0.5s=0.5, with uin=1u_{in}=1, giving the exact solution u=1+xu=\sqrt{1+x}. The target source is sin⁡(πx)\sin(\pi x). This example has no shocks and uses unlimited linear reconstruction.

ddx(u22)=s(x),x∈[0,1],u(0)=uin.\frac{d}{dx}\left(\frac{u^2}{2}\right)=s(x),\quad x\in[0,1],\qquad u(0)=u_{in}.

从守恒到通量差

From conservation to a flux difference

记物理通量为 F(u)=u2/2F(u)=u^2/2。对控制体 [a,b][a,b] 积分，用微积分基本定理，导数积分变为两个端点的通量差。这一步是有限体积法的起点：控制体内的源项总量，必须等于净流出通量。

Write the physical flux as F(u)=u2/2F(u)=u^2/2. Integrate over a volume [a,b][a,b] and use the fundamental theorem of calculus: the derivative becomes the difference of endpoint fluxes. This is the starting point of finite volumes: the integrated source equals the net outward flux.

∫abdFdx dx=F(u(b))−F(u(a))=∫abs(x) dx.\int_a^b \frac{dF}{dx}\,dx=F(u(b))-F(u(a))=\int_a^b s(x)\,dx.

After discretisation, neighbouring volumes can supply different states a,ba,b at the same face. A numerical flux H(a,b)H(a,b) turns these into one shared flux. Here a,ba,b denote states rather than integration endpoints. Consistency requires H(u,u)=F(u)H(u,u)=F(u). Sharing the same flux also makes interior contributions cancel in a global sum.

The dissipation coefficient is fixed at ε=0.8\varepsilon=0.8. The term −ε(b−a)-\varepsilon(b-a) damps state jumps and affects discretisation error. On the positive branch, the characteristic speed is F′(u)=u>0F'(u)=u>0, so primal information moves left to right and inlet data are prescribed on the left. Integrating uu′=0.5u u'=0.5 gives u2=1+xu^2=1+x; the positive root supplies the reference solution.

从一阶常值到二阶重构

From constant states to linear reconstruction

一阶格式在控制体内取常值。二阶内部斜率用中心差分，端点斜率用单边差分。虽然端点斜率本身只有一阶精度，但乘以 O(h)O(h) 的外推距离后，面值仍有 O(h2)O(h^2) 精度；实际全域阶数由网格加密验证。

First order uses piecewise constant values. Second order uses centred interior slopes and one-sided endpoint slopes. The endpoint slope is only first-order accurate, but multiplication by an O(h)O(h) extrapolation distance gives an O(h2)O(h^2) face value; mesh refinement checks the resulting global order.

把重构写成可以求导的加权和

Write reconstruction as differentiable weighted sums

二阶不是更换 Burgers 通量，而是用相邻数据估计面上的状态。以内部左迹为例，把中心斜率代入 qL=ui+(h/2)diq_L=u_i+(h/2)d_i，就得到三个非零权重。右迹同理；合起来一个面依赖四个未知量。这也解释了为什么二阶 Jacobian 比一阶更宽。

Second order estimates face states using neighbouring data while retaining the Burgers flux. Substitute the centred slope into qL=ui+(h/2)diq_L=u_i+(h/2)d_i to obtain three nonzero weights. The right trace works similarly; together a face depends on four unknowns. This explains the wider second-order Jacobian.

重构伪代码：一阶与二阶共用入口

trace(i, xf, u, order):

    if i == 0: slope = (u[1] - u[0]) / h

Try keeping the same face selected while switching order. Observe the traces, stencil points and flux. Second-order reconstruction reproduces a linear function exactly. This checks local reconstruction; global second order also depends on boundaries, source integration and mesh refinement.

第 3 节Section 3

边界条件：入口与出口

Boundary conditions: inlet and outlet

为什么只给一个入口条件

Why prescribe only one inlet condition?

定常方程在正解分支上是一阶常微分方程。给定 u(0)u(0) 后，积分就确定沿程的 u(x)u(x)；出口值应由内部解决定。再任意指定一个出口值，通常会过约束。离散时仍须提供出口通量，但“计算出口通量”与“另加出口值约束”是两件事。

On the positive branch the steady equation is first order. Once u(0)u(0) is specified, integration determines u(x)u(x) downstream. An arbitrary additional outlet value would generally overconstrain it. The discretisation still needs an outlet flux, but evaluating that flux is different from imposing an extra outlet-value constraint.

入口通量使用外部给定值 uinu_{in} 与从第一个单元重构至 x=0x=0 的内部迹。出口从末单元重构到 x=1x=1，再计算物理通量。二阶出口若仍直接使用末单元平均值，就会引入一阶边界误差。

The inlet flux uses the prescribed exterior value uinu_{in} and the interior trace reconstructed to x=0x=0. At the outlet, reconstruct from the final cell to x=1x=1 before applying the physical flux. Using the final cell average directly at a second-order outlet would introduce a first-order boundary error.

uinR=u0−h2d0,Hin=H(uin,uinR),uout=uN−1+h2dN−1,Hout=12uout2.u_{in}^{R}=u_0-\frac h2d_0,\quad H_{in}=H(u_{in},u_{in}^{R}),\qquad u_{out}=u_{N-1}+\frac h2d_{N-1},\quad H_{out}=\frac12u_{out}^2.

“边界对照”允许改用迎风通量 H=a2/2H=a^2/2：格心改入口面，格点改第一内部对偶面。它是另一种明确标记的离散边界闭合，用于第 15 节比较。格点二阶迎风面依赖重构斜率，因此它仍依赖相邻未知量。

The boundary comparison replaces one flux by H=a2/2H=a^2/2: the inlet face for cells, or the first internal dual face for nodes. This is a distinct, explicitly labelled boundary closure studied in Section 15. At second order, the node-based upwind face depends on its slope and therefore still on neighbouring unknowns.

对状态求导时，给定的入口值暂时固定，外部入口扰动为零；对入口设计变量求导时，它又是可以扰动的输入。这两个导数分别进入 A=RuA=R_u 和 RpR_p，不能混在一个状态模板里。边界对照改变的是离散方程本身，因此必须同时改变原始、前向、伴随和目标场。

When differentiating with respect to the state, hold the prescribed inlet fixed: its exterior perturbation is zero. When differentiating with respect to the inlet design variable, it is a perturbed input. These paths enter A=RuA=R_u and RpR_p separately. Changing the boundary comparison changes the discretisation and must be reflected in the primal, forward, adjoint and target field.

第 4 节Section 4

残差：收集、重构、计算、分发

Residual: gather, reconstruct, compute, scatter

残差是“还没有平衡的量”

A residual measures the remaining imbalance

把所有离散平衡式的右侧移到左侧，得到向量 R(u,p)R(u,p)。一个分量对应一个方程；Ri=0R_i=0 表示该控制体平衡。求解器的任务是找使全部分量同时为零的 uu。计算残差本身只是在给定 uu 后做一次函数求值，不会自动求出解。

Move each discrete balance to the left to form R(u,p)R(u,p). One component represents one equation; Ri=0R_i=0 means balance in that volume. The solver seeks a state making all components zero simultaneously. Evaluating the residual at a supplied state is only a function evaluation, not a solution of the equations.

面循环比逐行重复计算通量更直接：先把残差数组清零，再遍历每个面，重构状态、计算通量、向两侧累加，最后扣除源项。内部通量在两个方程中重复出现，却只计算一次。这里存储的是积分残差，没有除以控制体宽度 WiW_i；后面的 Jacobian、目标权重和伴随符号都按这一约定。

A face loop evaluates each shared flux once: zero the residual, visit each face, reconstruct states, compute the flux, add it to its neighbours, then subtract sources. An interior flux appears in two equations but is evaluated once. We store integrated residuals without dividing by volume width WiW_i; all Jacobians, objective weights and adjoint conventions follow this choice.

三个矩阵符号分别做什么

What the three matrix symbols do

TL,TRT_L,T_R 的一行存储一个面的重构权重；一阶每行通常只有一个 1，二阶每行通常有三个非零数。已知的入口常数另存为 bLb_L。B\mathcal B 的一列对应一个面，在左行放 +1+1、右行放 −1-1。所以矩阵写法只是把刚才的收集与分发打包，并没有增加新的数值方法。

TL,TRT_L,T_R store one face’s reconstruction weights per row: typically one unit entry at first order and three nonzero entries at second order. Prescribed inlet constants are stored separately in bLb_L. A column of B\mathcal B represents one face, with +1+1 in the left row and −1-1 in the right. The matrix notation packages gather and scatter; it introduces no new numerical method.

qL=TLu+bL,δqL=TLv(p fixed),δR=B δH.q_L=T_Lu+b_L,\qquad \delta q_L=T_Lv\quad(p\text{ fixed}),\qquad \delta R=\mathcal B\,\delta H.

这些矩阵式首先描述未经入口行替换的通量部分。出口只用左迹的物理通量；格点的第 0 行最后单独施加约束。播放器中的权重列表就是这些稀疏矩阵的非零项。

These matrix expressions first describe the flux contribution before inlet row replacement. The outlet uses the physical flux of its left trace, and the node scheme applies its row-0 constraint separately. The player’s weight lists are the nonzero entries of these sparse maps.

设计变量为每个原始区间上的常源项 σk\sigma_k 和入口值。源项先积分到控制体，面通量按左正右负分发。符号约定固定为“流出减流入减源项”。

Design variables are the constant source values σk\sigma_k on the primal intervals and the inlet value. Integrate sources over control volumes, then scatter each face flux with a positive sign to its left and a negative sign to its right. The residual convention is outflow minus inflow minus source.

Si=hσi,Ri=Hi+1/2−Hi−1/2−Si.S_i=h\sigma_i,\qquad R_i=H_{i+1/2}-H_{i-1/2}-S_i.

格点源项公式中不存在的区间项取零。将重构写为线性映射 TL,TRT_L,T_R，将面到控制体的有向分发写为 B\mathcal B，可以把两个空间阶数统一为下面的计算链。边界常数和入口行替换需要额外处理。

Missing interval terms in the node-based source formula are zero. Linear reconstruction maps TL,TRT_L,T_R and the oriented face-to-volume scatter B\mathcal B unify both spatial orders. Boundary constants and the inlet row replacement are handled separately.

u →TL,TR (qL,qR) →H Hf →B R=BH−S.u\ \xrightarrow{T_L,T_R}\ (q_L,q_R)\ \xrightarrow{H}\ H_f\ \xrightarrow{\mathcal B}\ R=\mathcal B H-S.

怎样使用逐句播放器：高亮行是刚执行的语句，变量表只显示已经算出的量，下层网格是执行后的累积数组。“下一步”前进一句；同一面内先得到左右迹，再算通量，最后分别更新左右残差。源项和入口约束也有独立步骤。符号 −1-1 只表示域外，访问数组之前会被排除。

Next advances one statement: left trace, right trace, flux, left update, right update. Sources and the inlet constraint have separate steps. Exterior index −1-1 is excluded before array access.

第 5 节Section 5

Jacobian 与 Gauss–Seidel 迭代

The Jacobian and Gauss–Seidel iteration

从 Newton 法得到线性修正方程

From Newton’s method to a linear correction

你熟悉的一元 Newton 法用切线逼近函数。对向量残差也是同样的思路：在当前状态附近作一阶 Taylor 展开，让线性近似的残差为零。矩阵 AijA_{ij} 表示第 jj 个未知量增加一点，会让第 ii 个残差改变多少。

Scalar Newton uses a tangent line to approximate a function. For a residual vector, use a first-order Taylor expansion at the current state and set the linear approximation to zero. The entry AijA_{ij} measures how residual ii responds to a small change in unknown jj.

A.1 Full derivation and well-posedness

1. 符号、积分测度与三类不同的检查

  2. 对同一离散问题做有限差分，检查 dJ_h/dp。

2. 适定性与伴随一致性不是同一件事

出现差异提供了诊断机会，但差异本身不能证明问题不适定。应先明确状态空间与边界迹空间、允许的数据、目标泛函以及范数。Hadamard 意义下的适定性要求解存在、唯一且连续依赖于数据。正确推导的连续伴随可以是适定的，而离散边界闭合却不一致；一个边界数据与目标泛函不匹配的适定方程，仍然是错误的伴随。约束乘子、有限正则性和参考解误差也会造成表观差异。

把原始边界条件的齐次线性化约束纳入算子 D:X→Y 的定义域 X。如果该算子是适当空间之间的有界同构，则其 Banach 伴随也是相应对偶空间之间的有界同构。这给出一种充分的局部分析框架，并不是写出形式微分表达式就能得到的结论。对于无界 PDE 算子，必须先明确其定义域及图范数，或者采用适当的弱形式。对于非线性原始问题，仅有存在唯一性还不能保证解映射可微；需要在所选解支上检查局部光滑性及线性化可逆性。

对于特征边界对照，每条内部射线都会在有限路程内到达出流边界。边界数据几乎处处确定内部场；切线或角点引出的跳跃可以在允许非光滑解的空间中处理，本身不意味着不适定。特征边界附近的比值 b_u/(a·n) 需要兼容性分析：在这里的物面目标中，分子与分母具有可相消的法向因子，不能只看分母就断言伴随发散。

其余算例说明了什么

对流扩散。 正扩散系数提供椭圆主部，但这不是任意低阶项与 Robin 边界系数下的普遍可逆性证明。仍需检查齐次零空间，以及所用能量估计或最大值原理的假设。独立计算支持当前参数组，没有证明对所有参数都成立的定理。把目标所要求的壁面伴随值 1 改成 0，可能得到另一个适定问题，但会给出错误的目标灵敏度。在远场同时规定状态值和法向导数，一般会过约束。把被替换方程行的乘子当成壁面场值，则是另一类代数含义错误。

拟一维 Euler。 对所述正向亚声速分支，特征速度 u−c,u,u+c 解释了原始入口两个条件、出口一个条件，以及伴随的相反条件数。条件数目正确是必要条件，不是充分条件：特征传播与边界约束共同组成的边值算子还必须可逆。声速点处 B 奇异，当前使用 (Bᵀ)⁻¹ 的表示失效，需要喉部兼容性／正则性分析。这不意味着所有跨声速伴随都不存在。激波还需要考虑激波位置变分及相应内部条件。这些现象超出当前数值证据的范围，可参考 Giles 与 Pierce 的连续喷管伴随分析。强、弱边界处理对数值伴随的不同影响，见 Duivesteijn 等人的研究。

因此，教学顺序应当是：先明确连续原始问题及所选解支；推导伴随，包括其边界定义域；分析存在性、唯一性和稳定性；随后才检查对该问题的一致、稳定逼近。反例应明确保留其失败的前提，不能悄悄替换模型后宣布验证成功。

7. 一维 Burgers：二阶重构、连续伴随与边界一致性

光滑正解分支与连续 tangent

考虑固定区间 [0,1] 上的定常方程，入口值为正。令源项的原函数从入口积分，选取正平方根：

(u22)′=s,u(0)=uin>0,u(x)=uin2+2∫0xs(t) dt.\left(\frac{u^2}{2}\right)'=s,\qquad u(0)=u_{in}>0, \qquad u(x)=\sqrt{u_{in}^2+2\int_0^x s(t)\,dt}.

只要根号内严格正且远离零，光滑解唯一，源项和入口扰动对解的映射稳定。令 v 为状态扰动，线性化得到：

(uv)′=δs,v(0)=δuin,v(x)=uinδuin+∫0xδs(t) dtu(x).(uv)'=\delta s,\quad v(0)=\delta u_{in},\qquad v(x)=\frac{u_{in}\delta u_{in}+\int_0^x\delta s(t)\,dt}{u(x)}.

教学基准采用 s=0.5、入口值 1，故 u(x)=sqrt(1+x)。目标场对应 s=sin(πx)，在求导期间固定。网格加密的 tangent 参考使用同一个物理扰动 δs=1、δu_in=0.2，而不是随网格缩小的单个源项区间。

从变分到终端伴随方程

目标函数是固定目标场的平方误差积分。令连续伴随 λ 满足以下终端值问题：

J=12∫01(u−uˉ)2 dx,δJ=∫01(u−uˉ)v dx,−uλ′=u−uˉ,λ(1)=0.J=\frac12\int_0^1(u-\bar u)^2\,dx,\qquad \delta J=\int_0^1(u-\bar u)v\,dx,\qquad -u\lambda'=u-\bar u,\quad\lambda(1)=0.

这里是 -uλ′，不是 -(uλ)′。原因是 tangent 微分算子作用于乘积 uv；其形式转置由下面的积分分部直接确定：

∫01λ(uv)′ dx=[λuv]01−∫01uλ′v dx=−uinλ(0)δuin+δJ.\int_0^1\lambda(uv)'\,dx =[\lambda uv]_0^1-\int_0^1u\lambda'v\,dx =-u_{in}\lambda(0)\delta u_{in}+\delta J.

代入 tangent 方程即可消去 v，得到连续总导数及可直接计算的伴随积分：

λ(x)=∫x1u(t)−uˉ(t)u(t) dt,δJ=∫01λ δs dx+uinλ(0)δuin.\lambda(x)=\int_x^1\frac{u(t)-\bar u(t)}{u(t)}\,dt,\qquad \delta J=\int_0^1\lambda\,\delta s\,dx+u_{in}\lambda(0)\delta u_{in}.

于是区间常源项的连续灵敏度是该区间内 λ 的积分，入口灵敏度是 u_in λ(0)。页面使用复合五点 Gauss 积分计算参考值，独立于离散伴随线性求解。

适定性与离散不一致是不同问题

若 u≥c>0，则终端条件唯一确定 λ，且有稳定性估计：

∥λ∥L∞(0,1)≤∥u−uˉu∥L∞(0,1)≤c−1∥u−uˉ∥L∞(0,1).\|\lambda\|_{L^\infty(0,1)} \le\left\|\frac{u-\bar u}{u}\right\|_{L^\infty(0,1)} \le c^{-1}\|u-\bar u\|_{L^\infty(0,1)}.

因此当前基准的连续伴随适定。离散伴随出现入口边界层，不应被解释为这个连续终端值问题不适定。若 u 接近或穿过零，以上稳定性界不再统一成立；若有激波，还需要弱解、激波位置变化及相应的伴随传递条件，不能套用这里的光滑推导。

二阶重构不会自动带来全域二阶伴随

格心未知量是单元平均值，格点未知量是节点值。二阶采用内部中心斜率、端点单边斜率，重构到真实面位置后计算通量。格心出口必须先重构到 x=1；格点第一内部对偶面位于 h/2，迎风通量也必须使用该位置的重构迹。

用 T_L、T_R 表示重构，用 B 表示有向面分发，忽略此行公式中单列的边界常数及约束替换，则精确二阶导数为：

R2=BH(TLu,TRu)−S,A2v=B{cL⊙TLv+cR⊙TRv},A2Tw=TLT{cL⊙BTw}+TRT{cR⊙BTw}.R_2=B H(T_Lu,T_Ru)-S,\qquad A_2v=B\{c_L\odot T_Lv+c_R\odot T_Rv\},\qquad A_2^Tw=T_L^T\{c_L\odot B^Tw\}+T_R^T\{c_R\odot B^Tw\}.

页面使用离散拉格朗日函数 J+ψᵀR，因此 A₂ᵀψ=-J_u，平衡方程对应的连续场应比较 λ 与 -ψ。格点第 0 行是强约束，乘子 ψ₀ 不能直接当作控制体内 λ 的取值；改为比较入口灵敏度 -ψ₀ 与 u_in λ(0)。

Q=I−e0e0T,A2=QAraw+e0e0T,A2Tw=ArawTQw+e0w0.Q=I-e_0e_0^T,\qquad A_2=Q A_{raw}+e_0e_0^T, \qquad A_2^Tw=A_{raw}^TQw+e_0w_0.

入口约束会移除该行的源项贡献；重构的转置又会把其他残差行的权重传回边界附近未知量。因此必须同时检查内部场、全域场、入口导数和首源项导数。当前计算显示：默认耗散入口下，二阶内部误差接近二阶，但全域误差受有限幅值局部边界层影响，接近半阶。格心迎风入口改善全域收敛；格点二阶迎风对照仍存在边界层。

首源项区间随网格缩小，其导数本身会趋于零；绝对差趋零不足以证明局部一致性。因此页面额外报告离散导数与连续区间积分的比值。对固定光滑物理扰动，则另外报告总方向导数误差。

GS 与 GMRES 只改变求解过程

令 P=A₁(u*) 是在收敛二阶状态处计算的一阶近似 Jacobian。每次从零开始执行固定次数 GS 扫描，形成线性近似逆 B_s。tangent 与 adjoint 的固定点迭代使用精确残差，GMRES 也使用精确二阶算子：

vm+1=vm−Bs(A2vm+f),ψm+1=ψm−BsT(A2Tψm+g),A2Bsz=−f,v=Bsz,A2TBsTy=−g,ψ=BsTy.v^{m+1}=v^m-B_s(A_2v^m+f),\qquad \psi^{m+1}=\psi^m-B_s^T(A_2^T\psi^m+g),\qquad A_2B_sz=-f,\quad v=B_sz,\qquad A_2^TB_s^Ty=-g,\quad\psi=B_s^Ty.

一次前向 GS 对应 B₁=(D+L)⁻¹；伴随采用对应的反向扫描 B₁ᵀ=(D+Lᵀ)⁻¹。这里的反向 GS 解的是 Pᵀ 系统。多次扫描也固定次数、零初值，以保持标准 GMRES 的预处理线性且固定。换成 GMRES 或把线性残差收敛得更小，都不能消除由离散边界闭合造成的伴随不一致。

1. Signs, measures and three distinct checks

Write the steady PDE as R(u,p)=0, the functional as J, and use

L=J−∫ΩλTR dΩ.\mathcal L=J-\int_\Omega\lambda^T R\,d\Omega.

The pages solve A_h^T ψ_h = −g_h. Our continuous multiplier has the opposite sign: λ_h=−ψ_h on conservation equations. Those residuals are integrated balances, so there is no additional division by control-volume measure. Rows replaced by algebraic boundary constraints carry constraint multipliers; their values are not point samples of the continuous field.

Three tests answer different questions:

  1. A transpose/dot test checks the implementation of A_h^T.
  2. Finite differences of the same discrete problem check dJ_h/dp.
  3. Comparing an independently solved continuous dual with a sequence of refined discrete duals tests consistency in a stated norm. It requires matching PDE, boundary conditions, functional, domain, and target data.

A decreasing error on finitely many meshes is numerical evidence, not a theorem of convergence. Boundary layers or characteristic jumps can prevent maximum-norm convergence even when an integral norm decreases.

2. Well-posedness is not the same as adjoint consistency

A discrepancy is a diagnostic opportunity, not by itself proof of ill-posedness. Specify the state and trace spaces, admissible data, functional, and norms first. Hadamard well-posedness requires existence, uniqueness and continuous dependence. A correctly derived continuous dual can be well posed while a discrete boundary closure is inconsistent; a well-posed equation with the wrong objective boundary data is simply the wrong dual. Constraint multipliers, limited regularity and finite reference error are other sources of apparent disagreement.

Linearization, kernels and stability

Include the homogeneous linearized primal boundary constraints in the domain X of the operator D:X→Y. If this is a bounded isomorphism between suitable spaces, its Banach adjoint is also a bounded isomorphism between the dual spaces. This is a sufficient local framework, not a conclusion obtained merely by writing a formal differential expression. An unbounded PDE operator must first be given a domain/graph norm or a suitable weak realization. For a nonlinear primal, existence and uniqueness alone do not guarantee a differentiable solution map; the local smoothness and invertibility hypotheses must be checked on the chosen branch.

For D*λ=g, a primal null mode implies the necessary compatibility condition

Dv=0⟹g[v]=⟨λ,Dv⟩=0.Dv=0\quad\Longrightarrow\quad g[v]=\langle\lambda,Dv\rangle=0.

A nonzero element of ker D* makes a solvable dual nonunique. Orthogonality to the primal kernel alone is not a general infinite-dimensional existence theorem: closed range and stability still matter. The required estimate has the form

∥λ∥Y∗≤C∥g∥X∗\|\lambda\|_{Y^*}\le C\|g\|_{X^*}

for homogeneous dual boundary data; inhomogeneous boundary data contribute their appropriate trace norm. A bounded inverse at every mesh size is not enough either: the stability bound must be uniform in the properly weighted discrete norms. Raw Euclidean condition numbers without accounting for integrated residuals and control-volume weights are not themselves a continuum diagnosis.

An explicit transport example

For c>0, fixed primal inflow and objective variation ∫₀¹g v dx+b v(1), the Green identity for the primal linearization c v' gives

−cλ′=g,cλ(1)=b,λ(x)=bc+1c∫x1g(s) ds.-c\lambda'=g,\qquad c\lambda(1)=b,\qquad \lambda(x)=\frac{b}{c}+\frac1c\int_x^1g(s)\,ds.
  • Missing outlet data: an arbitrary additive constant remains, so uniqueness fails.
  • An extra copied primal inlet datum λ(0)=0: existence requires b+∫g=0. With g=1,b=0, the correct solution is (1−x)/c; the extra inlet condition makes the problem unsolvable.
  • Loss of uniform stability: ‖λ‖∞≤(|b|+‖g‖₁)/c. Taking g=1,b=0 attains the 1/c amplification. Each fixed c>0 is well posed, but there is no bound uniform as c→0 for this data class. At zero speed the original operator degenerates.

In the original 2-D body example, normals point out of the fluid domain: the upwind body is therefore primal outflow. A characteristic already carrying u=1 cannot satisfy zero physical flux there. This is first a failure of the assumed smooth positive primal problem, not merely a poor discrete approximation to an otherwise established dual. At a putative wall state u=0,

δ(12u2β⋅n)=u(β⋅n)v=0\delta(\tfrac12u^2\beta\cdot n)=u(\beta\cdot n)v=0

for every variation v: the flux constraint loses its first-order information while the characteristic speed degenerates. Copying the wall condition onto a formal dual cannot restore a valid smooth solution branch. Weak/entropy formulations would need separate trace and differentiability analysis.

For the characteristic-boundary contrast, every interior ray reaches outflow in finite distance. Boundary data determine the field almost everywhere; tangency/corner jumps are compatible with a nonsmooth solution space and do not by themselves imply ill-posedness. The ratio b_u/(a·n) requires compatibility at characteristic boundaries: in this particular body objective its numerator and denominator contain a cancelling normal factor. One must not infer blow-up from the denominator alone.

What the other cases demonstrate

Advection–diffusion. Positive diffusion provides an elliptic principal part, not a universal invertibility proof for arbitrary lower-order and Robin coefficients. Homogeneous kernels and the assumptions of applicable energy or maximum-principle estimates still need attention. The independent solves support this parameter set; they do not prove a theorem for all parameters. Setting the wall dual to zero instead of the objective-required one can define a different well-posed problem, but yields the wrong functional sensitivity. Imposing both state and normal derivative at the far field is generally an overconstraint. Treating a replaced-row multiplier as a wall field sample is yet another, algebraic interpretation error.

Quasi-1-D Euler. The speeds u−c,u,u+c explain the two inlet/one outlet primal conditions and reversed dual counts for the stated positive subsonic branch. Counts are necessary, not sufficient: propagation and the boundary constraints together must yield an invertible boundary-value operator. At a sonic point B is singular, so the current representation using (Bᵀ)⁻¹ fails; throat compatibility/regularity analysis is required. This does not imply that all transonic adjoints fail to exist. Shocks require shock-position variations and internal conditions. These phenomena are outside the current numerical evidence; see the continuous nozzle analysis of Giles and Pierce. The distinct effects of strong/weak boundary treatment on numerical duals are discussed by Duivesteijn et al..

The teaching sequence is therefore: identify the continuous primal and chosen branch; derive the dual including its boundary domain; examine existence, uniqueness and stability; only then test consistent, stable approximation of that problem. A counterexample should retain its failed premise visibly, rather than silently substituting another model and declaring success.

7. One-dimensional Burgers: second-order reconstruction, continuous adjoints and boundary consistency

Smooth positive branch and the continuous tangent

Consider the steady equation on the fixed interval [0,1], with positive inlet data. Integrating the source from the inlet and choosing the positive square root gives:

(u22)′=s,u(0)=uin>0,u(x)=uin2+2∫0xs(t) dt.\left(\frac{u^2}{2}\right)'=s,\qquad u(0)=u_{in}>0, \qquad u(x)=\sqrt{u_{in}^2+2\int_0^x s(t)\,dt}.

As long as the radicand stays strictly positive and bounded away from zero, the smooth solution is unique and depends stably on source and inlet perturbations. Writing v for the state perturbation gives:

(uv)′=δs,v(0)=δuin,v(x)=uinδuin+∫0xδs(t) dtu(x).(uv)'=\delta s,\quad v(0)=\delta u_{in},\qquad v(x)=\frac{u_{in}\delta u_{in}+\int_0^x\delta s(t)\,dt}{u(x)}.

The teaching baseline uses s=0.5 and inlet value 1, hence u(x)=sqrt(1+x). The target corresponds to s=sin(πx) and remains fixed during differentiation. Tangent mesh refinement uses the same physical perturbation δs=1, δu_in=0.2, rather than a single source interval that shrinks with the mesh.

From variations to the terminal adjoint equation

The objective integrates the squared error against a frozen target. Define the continuous adjoint λ by the following terminal-value problem:

J=12∫01(u−uˉ)2 dx,δJ=∫01(u−uˉ)v dx,−uλ′=u−uˉ,λ(1)=0.J=\frac12\int_0^1(u-\bar u)^2\,dx,\qquad \delta J=\int_0^1(u-\bar u)v\,dx,\qquad -u\lambda'=u-\bar u,\quad\lambda(1)=0.

The operator is -uλ′, not -(uλ)′. The tangent differential operator acts on the product uv, and integration by parts directly determines its formal transpose:

∫01λ(uv)′ dx=[λuv]01−∫01uλ′v dx=−uinλ(0)δuin+δJ.\int_0^1\lambda(uv)'\,dx =[\lambda uv]_0^1-\int_0^1u\lambda'v\,dx =-u_{in}\lambda(0)\delta u_{in}+\delta J.

Substitution of the tangent equation eliminates v and gives both the continuous total derivative and an explicitly computable adjoint integral:

λ(x)=∫x1u(t)−uˉ(t)u(t) dt,δJ=∫01λ δs dx+uinλ(0)δuin.\lambda(x)=\int_x^1\frac{u(t)-\bar u(t)}{u(t)}\,dt,\qquad \delta J=\int_0^1\lambda\,\delta s\,dx+u_{in}\lambda(0)\delta u_{in}.

Thus the continuous sensitivity to a constant source on an interval is the integral of λ over that interval; the inlet sensitivity is u_in λ(0). The pages evaluate these references with composite five-point Gaussian quadrature, independently of the discrete adjoint linear solve.

Well-posedness and discrete inconsistency are different questions

If u≥c>0, the terminal condition uniquely determines λ, with the stability estimate:

∥λ∥L∞(0,1)≤∥u−uˉu∥L∞(0,1)≤c−1∥u−uˉ∥L∞(0,1).\|\lambda\|_{L^\infty(0,1)} \le\left\|\frac{u-\bar u}{u}\right\|_{L^\infty(0,1)} \le c^{-1}\|u-\bar u\|_{L^\infty(0,1)}.

The continuous adjoint of the present baseline is therefore well posed. An inlet boundary layer in its discrete counterpart must not be interpreted as ill-posedness of this terminal-value problem. If u approaches or crosses zero, the bound is no longer uniform. Shocks require weak solutions, shock-location variations and corresponding adjoint transmission conditions; this smooth derivation cannot simply be reused.

Second-order reconstruction does not automatically give a globally second-order adjoint

Cell unknowns are cell averages; node unknowns are point values. Second order uses centred interior slopes and one-sided endpoint slopes, reconstructing to the actual face locations before evaluating fluxes. A cell outlet must reconstruct to x=1. The first internal node-based dual face is at h/2, and even its upwind flux must use a trace reconstructed to that location.

Let T_L and T_R denote reconstruction and B denote oriented face scatter. With boundary constants and constraint replacement treated separately, the exact second-order derivatives are:

R2=BH(TLu,TRu)−S,A2v=B{cL⊙TLv+cR⊙TRv},A2Tw=TLT{cL⊙BTw}+TRT{cR⊙BTw}.R_2=B H(T_Lu,T_Ru)-S,\qquad A_2v=B\{c_L\odot T_Lv+c_R\odot T_Rv\},\qquad A_2^Tw=T_L^T\{c_L\odot B^Tw\}+T_R^T\{c_R\odot B^Tw\}.

The discrete Lagrangian is J+ψᵀR, giving A₂ᵀψ=-J_u. Balance rows therefore compare the continuous field λ with -ψ. Node row 0 is a strong constraint; ψ₀ is not a control-volume field value. Instead, compare the inlet sensitivities -ψ₀ and u_in λ(0).

Q=I−e0e0T,A2=QAraw+e0e0T,A2Tw=ArawTQw+e0w0.Q=I-e_0e_0^T,\qquad A_2=Q A_{raw}+e_0e_0^T, \qquad A_2^Tw=A_{raw}^TQw+e_0w_0.

The inlet constraint removes its row’s source contribution, while transposed reconstruction propagates weights from other residual rows to near-boundary unknowns. Interior fields, global fields, inlet derivatives and first-source derivatives must therefore be checked separately. Current calculations show nearly second-order interior adjoint errors for second-order reconstruction with the default dissipative inlet, while finite-amplitude local boundary layers reduce global convergence toward order one-half. An upwind cell inlet improves global convergence; the second-order node-based upwind comparison retains a boundary layer.

The first source interval shrinks with the mesh, so its derivative itself tends to zero. A vanishing absolute difference is insufficient evidence of local consistency. The pages additionally report the discrete derivative divided by the continuous interval integral. Total directional-derivative errors are reported separately for a fixed smooth physical perturbation.

GS and GMRES change the solver only

Let P=A₁(u*) be the first-order approximate Jacobian evaluated at the converged second-order state. A fixed number of zero-initialised GS sweeps defines a linear approximate inverse B_s. Tangent and adjoint fixed-point iterations use the exact residual; GMRES also retains the exact second-order operator:

vm+1=vm−Bs(A2vm+f),ψm+1=ψm−BsT(A2Tψm+g),A2Bsz=−f,v=Bsz,A2TBsTy=−g,ψ=BsTy.v^{m+1}=v^m-B_s(A_2v^m+f),\qquad \psi^{m+1}=\psi^m-B_s^T(A_2^T\psi^m+g),\qquad A_2B_sz=-f,\quad v=B_sz,\qquad A_2^TB_s^Ty=-g,\quad\psi=B_s^Ty.

One forward GS sweep gives B₁=(D+L)⁻¹; the adjoint uses the corresponding reverse sweep B₁ᵀ=(D+Lᵀ)⁻¹ on the Pᵀ system. Multiple sweeps also use a fixed count and zero initial values so that standard GMRES sees fixed linear preconditioning. Switching to GMRES, or converging linear residuals more tightly, cannot remove adjoint inconsistency caused by discrete boundary closure.

这个推导也解释了为何不能写成 G′(u(xₛ))·[u]：间断点的 u 没有唯一值，非线性 G 的跳跃是 [G]。对二次目标，[G]/[u]=(u_L+u_R)/2=s。若忽略激波位移，即使两侧光滑区的线性化都正确，也会漏掉整个位置导数。

This derivation explains why G′(u(xₛ))·[u] is not a valid replacement: u has no unique value at the jump, and the nonlinear jump is [G]. For a quadratic objective, [G]/[u]=(u_L+u_R)/2=s. Ignoring shock motion loses the entire position derivative even when both smooth-side linearisations are correct.

在两侧光滑区域形式上有 −λₜ−uλₓ=0，终端值为 qG′。但这不足以定义跨激波的伴随：必须包含界面移动的贡献。对此常值 Riemann 激波，把进入激波的初始特征线区域识别出来，得到下面的初始伴随平台。它满足 λ(a,0)·[u]=q(xₛ)[G]，从而恢复位置导数。交互在初始时刻画出这个解析参考；稀疏波没有激波平台，不画此参考。

In smooth regions the formal adjoint is −λₜ−uλₓ=0 with terminal data qG′. These equations alone do not define an adjoint across the shock: interface motion must be included. For this constant-state Riemann shock, identifying initial characteristics captured by the shock gives the plateau below. Its value times [u] recovers q(xₛ)[G]. The interaction overlays this analytic reference at the initial time; no shock plateau is drawn for a rarefaction.

稀疏波可直接在扇区内求导：dJ/da=−∫扇区 q(x)G′((x−a)/T)/T dx，边缘因状态连续而没有额外跳跃项。驻定激波 (1,−1) 的二次目标有 [G]=0，所以连续位置导数恰为零；数值上涂抹的激波可能产生非零的位置灵敏度。这里的差异是需要研究的结果，不能通过修改解析答案来“对齐”。

For a rarefaction, dJ/da=−∫fan q(x)G′((x−a)/T)/T dx; continuity at fan edges eliminates jump contributions. For the stationary (1,−1) shock and quadratic objective, [G]=0 and the continuous position derivative is exactly zero. A numerically smeared shock may produce nonzero position sensitivity. Such discrepancies are a result to investigate, not a reason to adjust the analytic reference.

还要区分另一种适定性问题：对稳态、无源的 (1,−1) 问题，左右通量相同，很多激波位置都满足相同边界数据，位置没有被唯一选定。其平移方向可能对应零模，稳态线性化可能奇异。这里的非定常问题通过初始位置 a 选定轨迹，因此不能用稳态的不唯一性否定当前离散时间程序的求导。

A separate well-posedness issue arises for the source-free steady (1,−1) problem. Equal boundary fluxes admit multiple shock positions; translation may form a null mode and make the steady linearisation singular. The transient initial position a selects a trajectory. Steady nonuniqueness therefore does not invalidate differentiation of this specified discrete time program.

Giles 与 Ulbrich（2010，第二部分）研究了激波处离散伴随的收敛，并展示了原始解收敛而伴随平台不正确的情形；其证明针对特定数值耗散及随加密增长的激波覆盖点数。本附录的固定 α、minmod 方法不自动满足该定理的假设。因此下方同时显示离散验证和连续参考误差，不把前者当作后者的证明。

Giles and Ulbrich (2010, Part II) analyse discrete-adjoint convergence at shocks and exhibit incorrect adjoint plateaux despite primal convergence. Their proof uses particular dissipation scaling and an increasing number of points across the shock under refinement. That theorem does not automatically cover this fixed-α, minmod scheme. The experiment reports discrete verification separately from error against the continuous reference.

Observed order is log₂(E_N/E_2N); these error definitions differ in shock-cut cells. The continuous-adjoint reference is sampled at cell centres. Branch-change counts refer to time levels with a change in either RK stage, not the total number of switched cells.

使用顺序：先比较两种空间离散的原始解和网格细化误差；再拖动时间层，看 tangent 如何集中到激波附近、伴随如何反向形成平台；最后改变 a（也可输入恰好位于网格面的数），比较单侧差分与中心差分。限幅分支改变的时间层数仅作诊断：小数值尾部的分支变化不一定显著影响目标，但不能忽略真实的不光滑点。

Suggested sequence: compare primal solutions and refinement errors for both spatial schemes; move the time slider to see tangent concentration and reverse-time adjoint evolution; then vary a, including positions exactly on mesh faces, and compare one-sided and central differences. The count of time levels with changed limiter branches is diagnostic: switches in tiny numerical tails need not affect the objective significantly, but actual nonsmooth points cannot be ignored.

B.8 小结与实现范围

B.8 Summary and implementation scope

本附录完整实现了三个 Riemann 问题的守恒时间推进、初值位置 tangent、反向时间离散 adjoint，以及解析解、质量平衡、点积和步长扫描验证。它没有实现任意激波相互作用的连续伴随，也没有证明当前耗散下伴随随网格加密收敛。教学的主线仍是对实际离散程序建立可核查的伴随；简单连续解用于验证和揭示局限。走向工业非结构网格 RANS 时，同样要交代限幅、边界、湍流闭合和求解过程的具体求导约定，不能假定存在一个可直接作为严格基准的完整连续伴随。

This appendix implements conservative time integration, initial-position tangents, reverse-time discrete adjoints, and analytic-solution, mass-balance, dot-product and step-size checks for three Riemann problems. It does not implement continuous adjoints for arbitrary shock interactions or prove adjoint convergence for this dissipation. The teaching focus remains an auditable adjoint of the actual discrete program. Simple continuous solutions expose both agreement and limitations. Industrial unstructured RANS additionally requires explicit differentiation conventions for limiters, boundaries, turbulence closure and solver operations; a complete continuous adjoint cannot simply be assumed to provide a rigorous reference.
